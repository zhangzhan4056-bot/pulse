第一章 策略分类框架

所有量化策略都在回答同一个问题：明天的价格会怎样？但回答的方式截然不同。

策略研究的第一步不是背公式，而是理解你在赌什么。每种策略背后都有一个关于市场本质的核心假设——假设决定了策略在什么环境下赚钱、什么环境下亏钱。

趋势动量

"涨的继续涨"
核心假设：价格有惯性。过去一段时间涨得好的资产，未来大概率继续涨。

市场观：牛市大赚，熊市大亏，震荡市被反复割。趋势策略本质上是在赌市场有方向。

典型指标：移动平均线、MACD、动量得分

代表人物：Gary Antonacci（双动量）、AQR Capital

均值回归

"跌多了会反弹"
核心假设：价格偏离均值后会回归。涨过头会跌，跌过头会涨。

市场观：趋势策略的天然对冲。牛市中可能踏空，但熊市底部抄底获利。震荡市是主场。

典型指标：RSI（相对强弱指数）、布林带

代表人物：DeBondt & Thaler（过度反应假说）

风险配置

"不预测，只分配"
核心假设：不预测方向，通过数学优化风险分配来获取收益。低波、低相关性资产长期跑赢。

市场观：牛市跑输，但回撤小、夏普高。依赖分散化和风险平衡。

典型指标：波动率、相关性矩阵、CVaR

代表人物：Bridgewater（全天候）、Edward Thorp

反脆弱

"从混乱中受益"
核心假设：不预测黑天鹅，而是构建凸性收益结构——平时小亏（保险费），暴跌时大赚（赔付）。

市场观：为尾部风险支付溢价。多数时间跑输纯动量策略，但极端市场中提供保护。

典型工具：OTM put 期权、Black-Scholes 定价

代表人物：Nassim Taleb（《反脆弱》）、Universa Investments

策略之间的对冲关系

这四种策略不是互相替代的，而是互相对冲的：

趋势动量 + 均值回归 = 天然对冲
动量在趋势市赚钱、震荡市亏钱；均值回归在震荡市赚钱、趋势市亏钱。两者组合可以平滑收益曲线。

风险配置 + 反脆弱 = 尾部保护
风险配置控制日常波动，反脆弱控制极端下跌。前者管"温差"，后者管"地震"。

第二章 核心术语与计算

理解策略之前，先理解语言。每个术语都附带公式、直觉解释和代码位置。

动量 Momentum
过去涨的继续涨
动量是最古老、最robust的量化因子之一。核心观察：过去 3-12 个月涨得好的资产，未来 3-12 个月大概率继续跑赢。这个现象在全球股票、债券、商品、外汇中都存在，跨越了 200 多年的数据。
单周期回报 = (Close[t] / Close[t-n] - 1) × 100

复合动量得分 = 1M×0.2 + 3M×0.3 + 6M×0.3 + 12M×0.2
映射到 0-100: score = (composite + 20) / 40 × 100, clamp [0, 100]
代码位置: core/strategy/indicators.py → calc_momentum_score(), calc_returns()

为什么有效？ 行为金融学解释：投资者对好消息反应不足（underreaction），价格调整滞后于基本面。机构解释：资金流入有惯性，基金经理抱团。

均值回归 Mean Reversion
偏离过大必回归
价格偏离历史均幅后，倾向于回归。涨过头的会跌回来，跌过头的会涨回来。RSI 是最常用的均值回归指标——RSI > 70 表示"超买"（可能要跌），RSI < 30 表示"超卖"（可能要涨）。
RS = 平均上涨幅度 / 平均下跌幅度（过去 14 天）
RSI = 100 - 100 / (1 + RS)

RSI > 70 → 超买（卖出信号）
RSI < 30 → 超卖（买入信号）
代码位置: core/strategy/indicators.py → calc_rsi()

为什么有效？ 市场过度反应：恐慌性抛售导致价格低于内在价值，贪婪性追涨导致价格高于内在价值。但注意：在强趋势中，均值回归会"接飞刀"——RSI 20 的资产可能继续跌到 RSI 10。

波动率 Volatility
价格变动的剧烈程度
衡量资产价格变动的"温度"。波动率高意味着价格剧烈波动（风险大），波动率低意味着价格平稳。年化波动率是将日度标准差放大到年度尺度。
日度标准差 = std(daily_returns, window=20)
年化波动率 = 日度标准差 × √252 × 100%

（252 = 一年的交易日数）
代码位置: core/strategy/indicators.py → calc_volatility()

在策略中的作用： 风险平价策略用波动率倒数做仓位分配（低波资产多配）；动量+波动率策略用波动率控制总仓位（高波时减仓）。

回撤 Drawdown
从高点下跌的幅度
回撤是投资者最直观感受到的"痛"。它不是从买入价算的亏损，而是从历史最高点算的下跌。最大回撤是历史上最深的那一次下跌。
回撤[t] = (Price[t] - Peak[t]) / Peak[t]
其中 Peak[t] = max(Price[0..t])

最大回撤 = min(回撤序列) × 100%
代码位置: core/strategy/indicators.py → calc_drawdown(), calc_max_drawdown()

在策略中的作用： 回撤控制策略用 SPY 回撤阈值决定仓位（-5% 减仓，-10% 清仓）。回撤约束优化用资产历史最大回撤做筛选（剔除回撤超 -40% 的资产）。

夏普比率 Sharpe Ratio
每单位风险的超额收益
最广泛使用的风险调整收益指标。夏普比率 = 1 表示每承担 1% 的波动率，获得 1% 的超额收益。夏普 > 1 是优秀，> 2 是顶级，> 3 可能是过拟合。
Sharpe = (年化收益 - 无风险利率) / 年化波动率

本项目默认：无风险利率 = 3%
代码位置: core/backtest/engine.py → _calc_metrics()

局限性： 夏普比率假设收益正态分布，但实际收益有"肥尾"——极端亏损比正态分布预测的更频繁。CVaR 是更好的尾部风险指标。

CVaR 条件风险价值
尾部平均损失 — 比最大回撤更稳健
CVaR（Conditional Value at Risk）回答的问题是："当情况变糟时，平均会亏多少？"它比最大回撤更稳健——最大回撤只看最深一次，CVaR 看最差 5% 情况的平均值。
1. 计算日度收益率序列
2. 取 VaR(5%) = 第 5 百分位数的损失
3. CVaR = 所有超过 VaR 的损失的平均值
4. 年化: CVaR_annual = CVaR_daily × √252 × 100%
代码位置: core/strategy/indicators.py → calc_cvar()

在策略中的作用： 尾部风险平价策略用 CVaR 做选股——选择"每单位尾部风险获得最高动量收益"的资产（得分 = momentum / CVaR）。

相关性 Correlation
资产联动程度 — 分散化的基础
相关性衡量两个资产价格变动的同步程度。相关性 = 1 表示完全同涨同跌，= 0 表示无关，= -1 表示完全反向。分散化的本质就是把低相关性的资产组合在一起。
ρ(X, Y) = Cov(X, Y) / (σ_X × σ_Y)

取值范围: [-1, 1]
滚动窗口: 60 个交易日
代码位置: core/strategy/indicators.py → calc_correlation_matrix()

关键洞察： SPY 和 TLT 的相关性在正常市场中为负（股跌债涨），但在通胀环境中可能转正（股债双杀）。这就是为什么需要动态计算相关性，而不是假设固定值。

MACD
趋势确认指标 — DIF / DEA / 柱状图
MACD（Moving Average Convergence Divergence）通过两条指数移动平均线的差值来判断趋势方向和强度。金叉（DIF 上穿 DEA）是买入信号，死叉是卖出信号。
DIF = EMA(12) - EMA(26)
DEA = EMA(DIF, 9)
柱状图 = (DIF - DEA) × 2

金叉: DIF 从下往上穿过 DEA → 买入
死叉: DIF 从上往下穿过 DEA → 卖出
代码位置: core/strategy/indicators.py → calc_macd()
MA 对齐 Moving Average Alignment
趋势的"骨架" — 短中长期均线排列
当短期均线 > 中期均线 > 长期均线时，称为"多头排列"——趋势向上，像一副整齐的骨架。反过来是"空头排列"。均线交织表示方向不明。
MA20 > MA50 > MA200 → 多头排列（看涨）
MA20 < MA50 < MA200 → 空头排列（看跌）
其他情况 → 交织（方向不明）
代码位置: core/strategy/indicators.py → calc_ma_alignment()
ATR 真实波幅
Average True Range — 衡量市场"温度"
ATR 衡量价格在一段时间内的实际波动范围，考虑了跳空缺口。比波动率更直观——ATR 是绝对值（美元/点数），波动率是百分比。
True Range = max(
  High - Low,
  |High - Prev_Close|,
  |Low - Prev_Close|
)
ATR = SMA(True Range, 14)
代码位置: core/strategy/indicators.py → calc_atr()
ADX 趋势强度
Average Directional Index — 区分趋势市和震荡市
ADX 只衡量趋势的强度，不衡量方向。ADX > 25 表示强趋势（适合趋势策略），ADX < 20 表示无趋势（适合均值回归策略）。
+DM = max(High - Prev_High, 0) （正向运动）
-DM = max(Prev_Low - Low, 0) （负向运动）
DX = |+DI - -DI| / (+DI + -DI) × 100
ADX = SMA(DX, 14)
代码位置: core/strategy/indicators.py → calc_adx()
Black-Scholes 公式
期权定价的基石 — 反脆弱策略的核心
Black-Scholes 是期权定价的标准模型。反脆弱策略用它来计算 OTM put 的公允价值（保险费），以及到期日的赔付金额。
d1 = [ln(S/K) + (r + 0.5σ²)T] / (σ√T)
d2 = d1 - σ√T

Put = K·e^(-rT)·N(-d2) - S·N(-d1)

其中:
S = 标的价格（SPY）
K = 行权价 = S × (1 - OTM%)
σ = 年化波动率
T = 到期时间（年）
r = 无风险利率
N() = 标准正态分布累积函数
代码位置: core/backtest/engine.py → _bs_put_premium()

直觉理解： BS 公式告诉你"为一份保险付多少钱是公平的"。波动率 σ 越高、到期时间 T 越长，保险越贵。OTM 越深（行权价越低），保险越便宜——但赔付触发门槛也越高。

第三章 趋势动量策略

"涨的继续涨" — 趋势动量是量化投资中最经典、研究最多的因子

趋势动量策略的核心逻辑：识别趋势 → 跟随趋势 → 在趋势反转时退出。区别在于如何定义"趋势"和"反转"。

趋势动量

趋势跟踪策略

均线排列 + MACD 双确认。当 MA20 > MA50 > MA200（多头排列）且 MACD 柱状图为正时，认为趋势确认。

核心逻辑

1 对每个资产计算 MA20、MA50、MA200
2 检查是否多头排列（MA20 > MA50 > MA200）
3 计算 MACD 柱状图，检查是否 > 0
4 多头排列 + MACD 正 → 满权重（1 单位）
5 仅多头排列（MACD 不正）→ 半权重（0.5 单位）
6 归一化：总权重 = 1.0
超额收益来源
  • 双确认机制减少假信号
  • 均线排列是趋势的"骨架"，MACD 是"肌肉"
  • 半权重机制降低不确定时期的暴露
失效场景
  • 震荡市：均线反复交叉，频繁假突破
  • V 型反转：均线滞后，错过底部
  • 需要 200 天数据预热，新资产无法立即参与
趋势动量

双动量策略

Gary Antonacci 经典策略。两层过滤：先用绝对动量过滤掉下跌资产（12 个月回报 > 0），再用相对动量选出最强的 top N，等权分配。

核心逻辑

1 计算每个资产的 12 个月回报: (Close[-1] / Close[-252] - 1)
2 绝对动量过滤: 只保留回报 > 0 的资产
3 如果没有正回报资产 → 100% 现金（空仓）
4 相对动量排序: 按回报降序，取前 3 名
5 等权分配: 每个资产 1/3
为什么叫"双动量"？
第一层"绝对动量"确保你只在上涨市场中持有资产（避开熊市）。第二层"相对动量"确保你持有最强的资产（优中选优）。两层保护，双重过滤。
超额收益来源
  • 绝对动量 = 熊市过滤器，大幅降低回撤
  • 等权分配简单 robust，不易过拟合
  • 学术验证跨越 200 年数据、全球市场
失效场景
  • 急速反转（如 2020 年 3 月）：动量信号滞后
  • 震荡市中所有资产回报接近 0，频繁进出
  • 12 个月回望期太长，错过短期拐点

趋势动量

动量 + 波动率过滤

动量选股 + 波动率控仓。选出最强动量资产，但根据波动率动态调整总仓位——市场"发烧"时自动减仓。

核心逻辑

1 计算所有资产的复合动量得分（0-100）
2 选取得分 ≥ 50 的前 3 名
3 计算入选资产的 20 日年化波动率
4 总仓位 = min(1.0, 目标波动率 / 平均波动率)
5 资产内按波动率倒数分配（低波多配）
6 最终权重 = 资产权重 × 总仓位
超额收益来源
  • 动量选股捕捉趋势
  • 波动率控仓在高波环境中自动降风险
  • 低波多配减少组合波动
失效场景
  • 低波动但持续下跌的市场（阴跌）
  • 动量得分和波动率同时上升时仓位骤降
  • 目标波动率 12% 在低波环境中可能过度保守
趋势动量

回撤控制策略

动量选股 + SPY 回撤阈值减仓。映射风控规则：-10% 减半仓，-15% 清仓。用 SPY 回撤作为组合风险的代理指标。

核心逻辑

1 动量选股：得分 > 50 的前 3 名，等权
2 计算 SPY 当前回撤: (SPY / SPY_peak - 1) × 100
3 回撤 → 仓位映射:
DD > -5%: 100% 仓位
DD -5% ~ -8%: 50% 仓位
DD -8% ~ -10%: 20% 仓位
DD < -10%: 0%（全现金）
超额收益来源
  • 系统化减仓，避免"扛单"心理
  • 用 SPY 做代理，不需要逐个资产监控
  • 阈值可映射到具体风控规则
失效场景
  • SPY 不是所有资产的完美代理
  • V 型反弹时已经清仓，错过回血
  • 阈值是静态的，不同市场环境的"正常回撤"不同

第四章 均值回归策略

"跌多了会反弹" — 趋势策略的天然对冲

均值回归和趋势动量是一枚硬币的两面。动量在趋势市赚钱，均值回归在震荡市赚钱。两者的组合可以平滑收益曲线。

均值回归

均值回归策略

基于 RSI 的反向交易。RSI 超卖（< 30）时重仓买入，RSI 正常时中等仓位，RSI 超买（> 70）时清仓。核心假设：价格偏离过大后会回归均值。

核心逻辑

1 计算每个资产的 14 日 RSI
2 RSI → 权重映射:
RSI < 30（超卖）→ 权重 1.0（重仓）
RSI 30-50（正常）→ 权重 0.7
RSI 50-70（偏高）→ 权重 0.3
RSI > 70（超买）→ 权重 0（排除）
3 归一化到 95%（保留 5% 现金）
超额收益来源
  • 超卖资产的反弹收益（行为金融学的过度反应）
  • 与动量策略天然对冲，组合后降低整体波动
  • 震荡市中表现优异
失效场景
  • 强趋势中"接飞刀"：RSI 20 的资产可能继续跌
  • 趋势市中可能严重跑输动量策略
  • RSI 是单一指标，容易被噪音干扰

第五章 风险配置策略

"不预测，只分配" — 通过数学优化风险分配来获取收益

风险配置策略不预测市场方向，而是通过优化资产之间的风险分配来获取收益。核心思想：低波动、低相关性的资产长期跑赢。

风险配置

风险平价策略

仓位与波动率成反比。波动率低的资产多配，波动率高的资产少配。最简单的风险配置策略。

核心逻辑

1 计算每个资产的 20 日年化波动率
2 过滤波动率 < 0.5% 的资产（可能是停牌或数据异常）
3 计算波动率倒数: inv_vol = 1 / volatility
4 归一化: weight_i = inv_vol_i / sum(inv_vol) × 0.95
超额收益来源
  • 低波资产长期跑赢高波资产（低波异象）
  • 组合波动率显著低于等权组合
  • 无需预测，纯数学驱动
失效场景
  • 牛市中严重跑输（高波资产涨更多）
  • 只看波动率，不看相关性
  • 波动率是向后看的，可能滞后
风险配置

低相关性组合策略

从相关性矩阵出发，构建最大化分散化的组合。与所有其他资产相关性低的资产获得更高权重。ERC（等风险贡献）思想的简化版。

核心逻辑

1 用 60 日滚动窗口计算相关性矩阵
2 对每个资产，计算与其他所有资产的平均相关性: avg_corr_i
3 转换为权重: inv_corr = max(0.01, 1 - avg_corr)
4 归一化到 95%
超额收益来源
  • 分散化降低组合波动
  • 低相关性资产在危机中提供缓冲
  • 动态适应市场相关性结构变化
失效场景
  • 危机中所有资产相关性趋向 1（分散化失效）
  • 相关性矩阵不稳定，60 日窗口可能太短
  • 不看收益，只看相关性，可能配到"正确但不赚钱"的资产
风险配置

尾部风险平价策略

CVaR + 动量联合优化。选择"每单位尾部风险获得最高动量收益"的资产。公式：得分 = momentum / CVaR。同时叠加 SPY 绝对动量过滤和波动率风险控制。

核心逻辑

1 宏观过滤: SPY 12 个月回报 ≤ 0 → 总仓位降至 30%
2 波动率控制: SPY 20 日 vol > 1.5× 中位数 → 进一步减仓
3 对每个资产计算 CVaR(5%) 和动量得分
4 过滤动量 < 40 的资产
5 得分 = 动量 / CVaR（每单位尾部风险的收益）
6 按得分比例分配
超额收益来源
  • CVaR 比波动率更关注尾部风险
  • 动量/CVaR 比率选择"收益好且尾部安全"的资产
  • 宏观过滤在熊市中大幅降低暴露
失效场景
  • CVaR 计算需要较长历史（252 天），新资产无法参与
  • 尾部风险和动量可能同时为负（最差资产）
  • 宏观过滤可能在 V 型反弹中错过机会
风险配置

回撤约束优化策略

动量 + 波动率 + 双层回撤约束。资产级：剔除历史最大回撤超 -40% 的"脆弱"资产。组合级：用 SPY 回撤阈值控制总仓位。

核心逻辑

1 动量筛选：得分 ≥ 50 的前 8 名候选
2 资产级约束: 剔除历史最大回撤 > -40% 的资产，保留前 4
3 波动率倒数分配基础权重
4 组合级约束: SPY 回撤 → 仓位映射:
DD > -8%: 100%
DD -8% ~ -12%: 60%
DD -12% ~ -16%: 30%
DD < -16%: 0%
超额收益来源
  • 双层约束：选股时剔除脆弱资产 + 持仓时动态减仓
  • 资产级约束基于历史最大回撤，更稳健
  • 组合级阈比回撤控制策略更宽松（-8% vs -5%）
失效场景
  • 历史最大回撤不代表未来（新黑天鹅）
  • 双层约束可能在极端市场中同时触发，仓位骤降
  • SPY 回撤阈值是静态的

第六章 反脆弱策略

"从混乱中受益" — 用期权构建凸性收益结构

理论基础：Taleb 的三态模型

Nassim Taleb 在《反脆弱》中将事物分为三种状态：

脆弱 Fragile

受冲击时受损。高杠杆、集中持仓、依赖预测。例：满仓单票。

稳健 Robust

受冲击时不受影响。分散化、低杠杆。例：60/40 股债组合。

反脆弱 Antifragile

受冲击时反而受益。凸性收益结构。例：持有 OTM put 期权。

凸性收益结构

反脆弱策略的核心是构建凸性收益结构：

凸性 = 损失有限，收益无限
花一小笔钱买保险（已知的最大损失），换取在暴跌时获得远超保费的赔付。

本项目实现：每月支付 ~0.5% 的保费（BS 公允价值），当 SPY 月跌超过 OTM 阈值时，获得非线性赔付——跌幅越大，赔付加速增长。

Black-Scholes 定价实现

每个再平衡周期，引擎执行以下步骤：

1 用 BS 公式计算 OTM put 的公允价值（保险费）
2 从组合价值中扣除保费
3 计算 SPY 本周期实际跌幅
4 如果跌幅 > OTM 阈值 → 计算内在价值赔付
5 赔付加回组合价值

赔付函数详解

如果 SPY 跌幅 ≤ OTM 阈值：
  赔付 = 0（保费损失）

如果 SPY 跌幅 > OTM 阈值：
  K = 100 × (1 - OTM%)   // 行权价
  S1 = 100 × (1 - 跌幅)   // 到期价格
  赔付 = max(K - S1, 0) / 100 - 保费

示例（5% OTM, SPY 跌 8%）：
  K = 95, S1 = 92
  内在价值 = 95 - 92 = 3
  净赔付 = 3% - 0.5%（保费）= 2.5%

第七章 策略组合与市场体制

没有万能策略。不同市场环境需要不同的策略。

市场体制识别

Market Pulse 通过 SPY、TLT、CL 的动量得分和 SPY 回撤来识别五种市场体制：

Risk-On 风险偏好
信号: SPY 动量 > TLT 动量 + 15 且 SPY > 60
含义: 市场乐观，资金流向风险资产
配置: 60% 核心 / 35% 卫星 / 5% 现金
策略: 趋势动量、双动量
Risk-Off 避险
信号: TLT 动量 > SPY 动量 + 15 且 TLT > 55
含义: 资金从股市流向债市
配置: 60% 核心(TLT 70%) / 20% 卫星 / 20% 现金
策略: 风险平价、低相关性组合
Stagflation 滞胀担忧
信号: CL 动量 > 70 且 SPY < 50
含义: 油价飙升 + 股市疲软
配置: 40% 核心 / 20% 卫星 / 40% 现金
策略: 反脆弱、尾部风险平价
Crisis 危机
信号: SPY 回撤 < -15%
含义: 深度下跌，避险为主
配置: 40% 核心 / 10% 卫星 / 50% 现金
策略: 回撤控制、反脆弱（此时赔付生效）
Range-bound 震荡
信号: SPY 和 TLT 动量接近，都在 40-60
含义: 方向不明，无明显趋势
配置: 50% 核心 / 20% 卫星 / 30% 现金
策略: 均值回归、风险平价

策略选择矩阵

市场环境首选策略次选策略避免策略
强趋势牛市趋势跟踪、双动量动量+波动率均值回归

暴跌/危机反脆弱、回撤控制尾部风险平价均值回归（接飞刀）
滞胀反脆弱、风险平价回撤约束优化趋势动量（股市疲软）

第八章 从回测到实盘

回测告诉你"过去会怎样"，但不保证"未来会怎样"。

回测的陷阱

常见陷阱
  • 过拟合：参数调到历史数据完美匹配，但未来失效
  • 前视偏差：用了未来才知道的信息（如用收盘价做当日决策）
  • 幸存者偏差：只回测现在还存在的资产
  • 交易成本低估：忽略滑点、冲击成本、税费
  • 数据窥探：反复在同一数据集上调参，直到"好看"
本项目的设计选择
  • 月度再平衡：减少交易频率，降低过拟合风险
  • 按日计算收益：避免只看月末的粗糙估计
  • 换手成本：按换手量 × 佣金率计算
  • 预热期：跳过前 252 个交易日，确保指标有足够数据
  • 数据诊断：页面显示每个资产的数据覆盖范围

交易成本的影响

本项目的佣金模型：成本 = 换手量 × 佣金率（0.1%）

换手量 = Σ|新权重 - 旧权重|
例：从 60% SPY / 40% TLT 变为 50% SPY / 50% TLT
换手量 = |50-60| + |50-40| = 20 个百分点
成本 = 0.2 × 0.1% = 0.02% 的组合价值

从回测到实盘的差距

因素回测实盘
交易成本简化模型（0.1% 固定佣金）滑点 + 冲击成本 + 税费
执行价格收盘价可能买不到/卖不到收盘价
数据质量历史数据可能有修正实时数据可能有延迟
心理因素无恐慌、贪婪、过度交易
市场影响假设不影响市场大资金会推动价格

给策略研究员的建议

  1. 先理解策略在赌什么，再看回测数字。回测好看不代表策略好。
  2. 关注失效场景比关注收益更重要。知道什么时候亏钱，比知道什么时候赚钱更有价值。
  3. 简单策略优于复杂策略。双动量（5 行核心逻辑）比很多复杂机器学习模型更 robust。
  4. 组合多种策略比押注单一策略更安全。趋势 + 均值回归 + 风险配置的组合，比任何单一策略都稳。
  5. 回测是必要条件，不是充分条件。通过回测的策略不一定好，但没通过回测的策略一定不好。
  6. 保持怀疑。夏普 > 3 的策略大概率是过拟合。年化 50% 的策略大概率是模型错误。
